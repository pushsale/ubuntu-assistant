# Ubuntu Assistant

Bộ công cụ tuỳ biến Ubuntu 26.04 (GNOME 50, Wayland).

| Thư mục | Nội dung |
|---|---|
| `remote-shield/` | Remote kiểu Windows: màn hình thật chuyển trắng khi có người RDP vào, người remote vẫn điều khiển desktop bình thường |
| `scifi-hud/` | GNOME Shell extension hiển thị CPU / RAM / GPU / nhiệt độ trên desktop |

Tài liệu: [docs/index.md](docs/index.md). Cài Remote Shield: [remote-shield/packaging/README.txt](remote-shield/packaging/README.txt).
